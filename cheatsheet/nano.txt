BUKA:
nano file.txt -> buka / bikin baru
nano -l file.txt -> tampilkan nomor baris
nano +10 file.txt -> langsung ke baris 10
nano +10,5 file.txt -> baris 10 kolom 5
sudo nano /etc/hosts -> edit file root

DASAR HIDUP MATI (wajib hafal 2 ini):
Ctrl+O -> Save (Write Out), Enter buat konfirmasi
Ctrl+X -> Keluar, kalau belum save ditanya Y/N
Ctrl+G -> Help lengkap

NAVIGASI:
panah -> gerak
Ctrl+F / Ctrl+B -> maju mundur 1 char (F forward B back)
Ctrl+P / Ctrl+N -> atas bawah (Prev Next)
Ctrl+A / Ctrl+E -> awal / akhir baris (kayak bash)
Ctrl+Y / Ctrl+V -> Page Up / Down
Alt+\ / Alt+/ -> awal / akhir file
Ctrl+_ -> Go to line number (Ctrl+Shift+-)

EDIT:
Backspace / Delete -> hapus
Ctrl+K -> Cut 1 baris (Kepotong)
Alt+6 -> Copy 1 baris (gak hapus)
Ctrl+U -> Paste (Uncut)
Ctrl+K terus Ctrl+U -> duplicate baris
Alt+A -> Mark / seleksi, lalu panah buat seleksi, Ctrl+K buat cut seleksi
Ctrl+J -> Justify / rapihin paragraf
Tab -> indent (atur di nanorc)

CARI & GANTI:
Ctrl+W -> Where is / cari, Enter, Alt+W cari lagi selanjutnya
Ctrl+\ -> Replace, isi yang dicari, Enter, isi ganti
Alt+R -> Regex mode pas Replace
Alt+C -> Case sensitive pas cari

UNDO REDO & INFO:
Alt+U -> Undo
Alt+E -> Redo (E lagi)
Ctrl+C -> Info posisi baris, kolom, char
Alt+D -> hitung kata/baris/char

FILE LAIN & MULTI BUFFER:
Ctrl+R -> Read / insert file lain ke posisi kursor
Ctrl+O lalu Ctrl+T -> browser file buat pilih nama save
Alt+< / Alt+> -> pindah buffer file sebelumnya / selanjutnya (kalau buka banyak file: nano file1 file2)
Ctrl+O Alt+P -> backup file asli jadi file~

TAMPILAN & OPSI:
nano -m -> aktifin mouse bisa klik & scroll (enak di WSL)
nano -B -> auto backup jadi file~
nano -c -> selalu tampilkan posisi kursor
nano -i -> auto indent
nano -A / -S -> smooth scroll

NANORC (config permanen):
file: ~/.nanorc
isi yang enak:

set linenumbers
set tabsize 4
set tabstospaces
set autoindent
set mouse
set softwrap
set constantshow
set historylog
set positionlog
set zap # backspace hapus seleksi
set atblanks
include "/usr/share/nano/*.nanorc" # syntax highlight semua bahasa
